# AI Delegation Boundary — 日本語版クイックガイド

**AIに任せる範囲を考慮する。**

このアプリは、AIに任せる条件を検討・検証し、人が承認した版だけを反映するための作業スペースです。「反映」は、このアプリ内の委任条件を確定することです。実際の返金や外部システムでの業務処理を実行するものではありません。

## 日本語で始める

画面上部の **日本語** を選びます。URLの末尾に `?lang=ja` を付けても開けます。英語に戻すには **EN** を選びます。表示言語はブラウザに保存しますが、保存が制限されていても画面上の切替は利用できます。

このブランチをローカルで確認する場合は、`npm ci`、`npm run dev` の順に実行し、表示されたURLを開いてください。日本語版の公開反映は別途行います。

## 基本の操作

1. **業務を定める** — 「検討する業務」に、AIに任せたい仕事と背景・制約を記入します。例：顧客への返金申請を確認する。
2. **処理と判断の根拠を整理する** — 「AIに、どの処理まで任せますか」に、任せたい処理、判断に使う資料・ルール、間違った場合の影響を記入します。不明な点は空欄で構いません。この欄は再読み込みで消える検討用メモです。
3. **AIに検討を依頼する** — WebMCP対応環境で通常の5ツールが利用可能になったら、画面に表示される文面をコピーし、ChatGPTの現在の会話に送信します。日本語の文面は、AIにも日本語での説明を依頼します。
4. **検討課題に回答する** — 「AIだけで完了してよい」「人の確認を残す」「AIに任せない」から選びます。人の判断は、後の変更で覆されていないか確認するテストとして残ります。
5. **矛盾を解消して再検証する** — 必ず守る制約や過去の判断と矛盾する場合は、画面の案内に従って委任条件を修正します。条件が変わるたびに、現在の版に対する新しい検討課題が必要です。
6. **人が承認する** — 検証を終え「承認可能」になったら、内容を確認して、その版を承認します。承認だけでは反映されません。
7. **反映して完了する** — 「第N版を反映して完了」を押します。ChatGPTへの追加の貼り付けは不要です。承認内容との一致を再確認した後、完了レポートを表示します。

任意で、承認後に表示される専用の文面をChatGPTへ送り、WebMCP経由で反映することもできます。どちらの方法でも、同じ承認済みの版だけを反映します。

## 表示される状態

| 状態 | 意味・次の操作 |
| --- | --- |
| 検討中 | AIによる提案・検討や、人による回答を進めます。 |
| 人の判断待ち | 課題への回答や、検証条件の確認が必要です。上部の案内を確認してください。 |
| 修正が必要 | 必須制約または過去の判断と矛盾しています。条件の修正が必要です。 |
| 承認可能 | 検証済みです。人が内容を確認して承認します。 |
| 人が承認済み | 承認した版を反映できます。まだ完了ではありません。 |
| 反映済み | 完了です。完了レポートで反映した版と検証結果を確認できます。 |

## 安全に使うために

- 言語切替で、入力内容、判断、承認済みの版、フィンガープリントは変わりません。
- 人やAIが書いた業務名・課題・変更理由は原文を保ちます。以前の英語の記録は、日本語表示に切り替えても自動翻訳しません。
- エラーが起きた場合は、日本語の案内を表示します。未対応の診断情報は、詳細を失わないよう原文を併記します。
- WebMCP非対応のブラウザでも人の操作画面は使えますが、AIの提案・検討課題を含む一連の検証には対応環境が必要です。
- 現在の作業はブラウザのセッションに保存されます。サーバーへの永続保存や組織の監査記録を提供するものではありません。
- 「新しい業務」で消去を確定すると、現在のセッションの作業記録は失われます。必要な内容を先に控えてください。

## 開発・確認範囲

翻訳は表示層で行います。判定エンジン、WebMCPのツール名・スキーマ、承認・反映処理は変更しません。`npm test` では既存の案内状態に対しても日本語化後の遷移先と元データの不変性を確認します。`npm run build` で型チェックと本番ビルドを確認できます。

## 条件設定について

現在の条件表は「詳細設定」にあります。個別案件について確認済みの事実ではなく、AIに任せるための条件を定める欄です。「元に戻せるか」の対象はAIに任せる具体的な処理です。例えば、メールの下書きは直せますが、送信後に相手が読んだ内容は戻せません。

処理ごとの整理・提案は、コピーした依頼文をWebMCP対応のChatGPTへ送って行います。このページ単体ではAI分析や自動的な処理分解は実行しません。現在の判定モデルは共通の判断項目を使うため、複数の処理ごとに独立した条件を保存・評価する機能はありません。依頼文でも、表現できない区別や未確認情報を明示するよう求めます。
